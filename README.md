# 🌸 GrowDay

GrowDay is a habit-tracking web application designed to help users build better habits one day at a time.

## ✨ Features

- 🌱 Recommended habits
- 💕 Create custom habits
- 🔐 User registration and login
- 📊 Personal dashboard
- 🔥 Habit streak tracking
- 📅 Habit history
- 🎀 Cute pastel user interface

## 🛠️ Technologies Used

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- CSS
